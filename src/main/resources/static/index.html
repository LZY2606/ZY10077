  • 只有日志和物理探测互相印证，才允许继续。
    • 
          
  • 回填使用 where id > cursor order by id，插入幂等，不按步骤名重跑。
    •

    • 
          
  • 完成必须同时具备终局结构、逐行数据一致和完整哈希链。
    • 
          
  • 原始证据只追加保存；分析派生物带规则版本和来源指纹。
